# LEX_A · Судова практика — Telegram Mini App (тестова версія)

Один статичний файл `index.html`: правові позиції Верховного Суду та практика покарань за підслідністю СБУ, НАБУ/САП (ВАКС), БЕБ, ДБР.

Джерела: відкриті дані ДСА (ЄДРСР, ліцензія CC BY), правові позиції ВС (lpd.court.gov.ua). Розбір вироків автоматичний — перед цитуванням звіряйте з текстом рішення. Статистики за суддями немає.

Збирається з бази знань LEX_A (`build_lexa.py`); не редагуйте `index.html` вручну.
