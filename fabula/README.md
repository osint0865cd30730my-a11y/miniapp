# Fabula — бот і черга постів каналу @fabula_crime

Щодня о 19:00 (за Києвом) бот надсилає власникові чернетку поста з `queue.json`. У канал пост іде лише після «✅ Опублікувати».

| Файл | Що це |
| --- | --- |
| `worker.js` | код бота для Cloudflare Workers (окремий воркер `fabula-bot`, не плутати з `bot/worker.js` LEX_K) |
| `queue.json` | черга постів (дата, рубрика, текст, картка, кнопки, опитування) |
| `cards/*.jpg` | картки 1080×1080, бот показує їх великим прев'ю над текстом |
| `tools/week1.py` | тексти постів → `queue.json` і `tools/cards.json` |
| `tools/cards.py` | малює картки з `tools/cards.json` (Playwright) |

## Запуск (один раз)

1. **Бот.** У Telegram: @BotFather → `/newbot` → назва, наприклад «Fabula», адреса на кшталт `fabula_crime_bot`. Токен нікуди не пересилайте: він знадобиться лише на кроці 4.
2. **Канал.** @fabula_crime → Адміністратори → Додати → ваш новий бот, право «Публікувати повідомлення» (і «Закріплювати», щоб бот закріпив вітальний пост).
3. **Воркер.** dash.cloudflare.com → Workers & Pages → Create → Create Worker → назва `fabula-bot` → Deploy → Edit code → замінити вміст на `worker.js` → Deploy.
4. **Змінні** (Settings → Variables and Secrets):
   - `BOT_TOKEN` — тип **Secret**, токен з кроку 1;
   - `CHANNEL` — `@fabula_crime`;
   - `QUEUE_URL` — `https://osint0865cd30730my-a11y.github.io/miniapp/fabula/queue.json`;
   - `OWNER_ID` — ваш id (див. крок 7; спершу можна пропустити).
5. **Сховище.** Storage & Databases → Workers KV → Create → `fabula-state`. Воркер → Settings → Bindings → Add → KV namespace: змінна `STATE`, сховище `fabula-state`.
6. **Розклад.** Воркер → Settings → Trigger events → Add → Cron: `0 17 * * *` (19:00 за Києвом узимку). З 29 березня, коли Україна перейде на літній час, змінити на `0 16 * * *`.
7. **Підключення.** Відкрити `https://<адреса воркера>/setup`. Написати новому боту `/id`, вписати число в `OWNER_ID`, ще раз відкрити `/setup`. У відповіді має бути `"webhook":true`, `"owner":true`, `"kv":true` і кількість постів у черзі.
8. **Перевірка.** Написати боту `/fabula` — стан черги. `/pin` — чернетка вітального поста: після «Опублікувати» бот сам його закріпить.

## Щодня

- О 19:00 приходить чернетка поста на сьогодні: «✅ Опублікувати», «🔁 Інший» (пост із резерву замість цього), «✖ Пропустити».
- Виправити текст: дайте відповідь (reply) на чернетку новим текстом, бот надішле оновлену чернетку. Жирний і курсив зберігаються.
- Для «Ви — суддя» після поста бот сам публікує опитування.
- `/zaraz` — чернетка на сьогодні вручну, `/rezerv` — пост із резерву.
- Коли в черзі лишається менше ніж на три дні, бот нагадує.

Токен бота зберігається лише в секретах Cloudflare. Репозиторій публічний — токенів і id у ньому немає й не повинно бути.
